# SalesInsight PY

Pipeline de análise e visualização de dados de vendas em Python.

## 🚀 Objetivo
Criar um fluxo completo de análise que:
- Gera ou carrega um dataset de vendas.
- Limpa e trata inconsistências.
- Cria colunas derivadas (receita, mês, trimestre, ano).
- Calcula métricas agregadas.
- Segmenta clientes por nível de gasto.
- Gera visualizações informativas.
- Exporta relatórios em CSV e gráficos em PNG.
